# 攻擊動畫（2026-10-31）

所有有攻擊能力的部隊、軍團成員、四位領主及攻擊建築，使用既有單張素材的程序動畫：前衝、傾身、後座、縮放及墨線軌跡。紅藍使用相同動作並鏡像，不另製第二套素材。

| 類型 | 動作 |
|---|---|
| 一般近戰、長槍、農具 | 短前衝、刺擊線與揮擊弧線 |
| 騎士、巨人、收割者、戰鬥領主 | 重揮、較大幅前傾與恢復 |
| 獵戶、箭樓 | 射擊後座、放弦速度線 |
| 投石車 | 發射後座、機身回彈與塵土 |
| 耕牛、攻城槌 | 向前撞擊、短暫壓縮與揚塵 |
| 烏鴉 | 向前下方俯衝啄擊 |
| 法師、草藥婆、冥府／豐收領主 | 施法傾身、符光環與星點 |
| 戰鼓手 | 擊鼓下壓與震波 |

`attack_animation.gd` 只觀察實際攻擊與支援計時器重新啟動，不寫入戰鬥狀態，不改傷害、命中、射程、冷卻、移動或亂數。動畫時間取對戰時間，暫停時固定，觀戰倍速同步。死亡移除與重開會清理動畫；關閉特效時不顯示攻擊變形與軌跡。軍團的每位成員獨立追蹤。

驗收工具 `tools/capture_attack_animation.gd` 逐頁拍攝紅藍所有攻擊者的出手、恢復與靜止三個階段；圖片位於 `docs/attack-animation-preview/`。實戰截圖另存 `battle-live.png`。

新增測試確認每個部隊的攻擊會觸發、觀察不改戰鬥資料、重複觀察不重播、到時回位、領主與箭樓有動畫、過期清理及重新開始重置。既有教學測試改用固定種子，先驗證敵方甦醒，再隔離敵方反攻驗證破門通行，消除時間種子造成的偶發失敗；遊戲教學流程未改動。

驗證結果：主工作目錄 headless 與視窗版 smoke_test 均為 818 checks、0 failures；只套用本次動畫修改的獨立基線為 810 checks、0 failures，全部回傳 0。已重拍分頁動畫階段、preview 與第 60 秒實戰截圖並檢視；沒有修改平衡或重錄黃金對局。
