# 首頁與啟動驗收（2026-10-31）

首頁採左側羊皮紙選單、右側兩軍對沖；人類軍團後方為農田，亡靈後方為墓碑，不使用城堡。開始對戰為主按鈕，其餘功能分列，保留難度與已選領主資訊。按鈕提供滑鼠懸停、按下及鍵盤焦點樣式。

## 啟動修復（最終實作）

遊戲直接開啟 main.tscn 的首頁，沒有額外載入頁。藍方配色提前在開發／發佈準備階段產生，存放於 assets/generated-palette。這些是單套原圖自動產生的衍生檔，不人工維護第二套美術。正常啟動只讀取已匯入的紋理，不做逐像素換色，也不依賴玩家的使用者快取。

manifest.json 記錄原圖 SHA-256、換色規則版本、尺寸及素材名稱。原圖改變只重建該圖；UI 或平衡改動不重建。修改 team_material 或換色算法時必須遞增 PALETTE_REVISION。原圖缺少對應衍生檔時，開發用的原始轉換仍可使用，但應在交付前準備完成並跑啟動檢查，避免把重算帶給玩家。

## 素材更新與發佈流程

1. `godot_console --headless --path . -s tools/prepare_assets.gd`
2. 有產生新檔時，`godot_console --headless --path . --import`
3. `godot_console --path . -s tools/test_startup.gd`
4. 將變更的原圖、衍生圖與 manifest 一併提交；僅編輯原始素材，勿手動改衍生圖。

第二次準備實測：Prepared 0, reused 31；沒有重做換色。啟動測試用全新的 APPDATA：首頁初始化 1,367 ms，32 個藍方紋理引用（包含城堡別名）全數來自預處理素材，沒有執行換色。修改前直接初始化為 8,955 ms。以上是開發機量測，不包含 Godot 程序本身啟動時間。

tools/measure_startup.gd 可量測直接初始化時間。tools/test_startup.gd 檢查直接到達首頁，且所有藍方素材都引用預處理結果；缺漏會回傳失敗。首頁與第 60 秒實戰截圖已檢視，中文字型已重切；不改戰鬥數值、AI 或黃金對局。

最終驗證：headless 與視窗版 smoke_test 均為 818 checks、0 failures、回傳 0；預處理後的首頁與實戰截圖已重新檢視。
