# 1-1 邊境農莊開場

所有冒險對手改用一般對戰的出牌 AI，不再按波次生成敵人。第一關開場使用固定合法出牌時機，其後交還 AI 自行決策；原有守城、破城、經濟關卡目標保留。

## 正常出牌演出

- 第一關只有中央一條可用路；玩家初始兩座農田，敵方據點顯示強盜帳篷。
- 第 0 秒經由 `Battle.play` 打出農民，第 0.5 秒經由同一接口打出敵方乾草叉暴民牌（本關使用強盜外觀）。正常扣款、手牌補位、出兵間隔、行軍、耕作、攻擊、死亡與拆建。
- 強盜沒有新數值或獨立收藏卡；本關敵方暴民、民兵使用強盜立繪。潛行是畫面表現，不另加隱形或免傷規則。
- 固定種子下，前方田地約 8.3～8.6 秒耕完；農民約 10.4～12.1 秒陸續戰死，敵軍拆田後約 20.3 秒抵達村口。這是試跑結果，不是強制扣血時間表。
- 當農民確實陣亡、一座田確實損毀、敵軍實際抵達村口，才讓領主登場、宣告反攻，解鎖玩家操作與正常敵方 AI。
- 暫停凍結整個戰局；重新開始重置開場；普通對戰維持五路。

## 美術與驗收

- 新增透明背景強盜、強盜帳篷，分別以現有農民及城門素材作畫風參照；生成描述存於 `assets/manuscript-v1/bandit-prompts.json`。
- 預覽位於 `opening-preview/`：耕作／接敵／拆田／進逼／宣言／AI 對戰。
- `tools/test_farm_opening.gd` 檢查正常出牌數與卡種、耕作、真實拆田、領主登場、暫停、重試、單路單位與建築，以及其餘關卡啟用 AI。
- 共用目錄仍有其他數值與機制修改；完整回歸另以本次提交內容的隔離副本執行，不改寫其黃金對局。

驗收結果：專項測試通過；快速測試 249 項通過；隔離完整測試 884 項、0 failures。
