# 冒險十關（2026-11-02）

1–3 關由強盜、叛逃民兵構成敵軍，對話揭露東邊戰亂與重稅。第 3 關的獵戶代表叛軍弓手，直接使用正式獵戶卡。
4–6 關逐步遇到亡靈，依序取得運貨帳目、接頭信、雙方契約，證明人類軍需官以糧食和兵器交換亡靈軍隊。
7–9 關支援紅獅、豐收、鐵壁三位領主；第 10 關對抗亡靈領主。
