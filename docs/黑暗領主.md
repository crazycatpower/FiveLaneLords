# 黑暗領主（設計稿，2026-11-03，交給 Codex 實作）

數值一律寫檔次（見《數值檔次》），實作時用 `B.tier_value()` 換算。

## 定位

黑暗陣營的第二位領主。冥府領主靠墓碑「主動召喚」骷髏；黑暗領主走「靠戰鬥壯大」的路線：在一場大混戰中發動技能，讓敵人越死越多、我方越打越壯。

| | 冥府領主 | 黑暗領主 |
|---|---|---|
| 經濟 | 墓碑 | 農田（預設，不另做常駐建築） |
| 技能時機 | 有墓碑就能放 | 要等雙方大量交戰才划算 |
| 骷髏來源 | 自己的墓碑 | 敵人的屍體 |

- 內部代號 `dark_lord`，陣營 `dark`，`role`「腐化型」。
- 可用黑暗牌＋中立牌，牌池同冥府。
- 本體：生命 A、普攻 A、移速 D。普攻比一般領主高一檔，因為技能期間本人也會上前吸血。

## 技能「永夜降臨」

- 費用 15，冷卻用共用的 `SKILL_COOLDOWN`；開場冷卻同其他領主。
- 持續 8 秒，期間：
  1. **亡者為奴**：場上所有敵方部隊視為被詛咒。8 秒內死掉的敵方部隊，在原地變成我方骷髏兵，一隻敵人換一隻骷髏。直接沿用詛咒卡的 `cursed_until`／`curse_team`，到期自動失效。施放當下在場的敵人，加上 8 秒內新出的敵人，都算在內。
  2. **吸血**：我方部隊和黑暗領主本人造成的傷害，有 30% 轉成自身生命，最多補到滿血。建築、法術、投射物爆炸不吸血。
- 不影響：建築、城門、領主（敵方領主死亡不會變骷髏）、飛行單位。飛行的敵人死了照樣會變骷髏，但骷髏走地面。
- 和時空凝滯同時發生時，8 秒倒數跟著戰局時鐘暫停。

## 畫面（不用文字）

- **施放瞬間**：從黑暗領主腳下擴散一圈深紫黑的波，全場慢慢暗下來。用暗角疊色，不要整片蓋黑，部隊和格子都要看得清楚。
- **持續中**：
  - 頂部計時器旁出現一輪細月，隨 8 秒倒數從滿月縮成弦月，取代數字。
  - 敵方部隊腳下有淡紫色的詛咒印。
  - 我方部隊吸到血時冒出小紅點，飛回攻擊者身上。
- **敵人死亡**：沿用詛咒卡的 `curse_rise` 效果和連線，只把顏色換深。
- **結束**：暗角在 0.6 秒內退去。
- **技能按鈕與領主列圖示**：沿用現有的光芒、布幕、寶石、金幣規則。
