# 法師新單位：魔法陣營五張進攻牌（交給 Codex 實作）

> 2026-11-03 製作人：法師領主勝率長期墊底（十檔平衡後仍只有約 38%）。原因是好用的單位太少、進攻性不足；目前只能組中立牌，而中立牌裡能推進的部隊不是太弱（強盜），就是太慢（攻城槌、投石車）。
> 本文件設計五張**法師專屬**部隊牌，主題是「時間與空間」，跟法師技能「時空凝滯」同一個方向。
> **數值一律用檔次字母表示**。實作時從 `B.TIERS` 抄對應的值（對照見 `docs/數值檔次.md`）；範圍傷害欄位查 `area_damage` 表，範圍欄位查 `radius` 表。費用和冷卻是起始估計，實作完後用自動調費修正。

## 0. 新陣營「魔法」（已完成，2026-11-03）

> 這一節已經實作：陣營表、法師領主、驗證訊息、組牌畫面標籤與說明、說明頁、測試都改好了。原本的五張祕法卡牌（工匠、水晶、傳送法陣、爆炸法陣、祕法塔）也已改成魔法陣營。`tools/test_faction_expansion.gd` 目前要求魔法牌 5 張、法師牌池 16 張；加完本文件的五張後改成 10 張、21 張。

五張牌只給法師用，所以新增一個陣營，做法跟冥府領主的黑暗牌一樣：

- `balance.gd`：`FACTIONS` 加 `"magic":"魔法"`；法師領主的 `faction` 從 `""` 改成 `"magic"`。
- 法師因此可以用「魔法牌＋中立牌」，跟其他領主一樣是「自己陣營＋中立」；`card_allowed()` 的邏輯不用改。
- 水晶依已完成的 v6.34 決策為魔法牌，法師常駐格照舊；其他領主不可組入。
- 要改的文字與介面：
  - `validate()` 的陣營錯誤訊息。
  - `game.gd:590` 的陣營標籤顏色（建議紫色 `6a4c8c`）。
  - `game.gd:1377` 的「法師領主可用：中立牌」改成「魔法牌與中立牌」。
  - `docs/法師領主.md` 的「只可組中立牌」。
- 五張牌都加 `"faction":"magic"`、`"series":"magic"`（卡框沿用黑暗紀元的做法，換成紫色調）。

## 1. 閃現劍士（`blink_blade`）

**定位**：敵人越想擋住它，它越往前鑽。對付靠前排擋路的陣型（盾衛、木拒馬、稻草人）特別有效。

| 欄位 | 值 |
|---|---|
| 人數 | 2 |
| 生命 | D |
| 傷害 | B |
| 攻擊間隔 | C |
| 射程 | G（近戰） |
| 移速 | C |
| 新欄位 | `"blink_step": 0.25`（每次閃爍距離＝格寬 × 0.25） |

**機制：受傷閃爍**
- 每次受到傷害（普攻、範圍傷害、毒霧每一跳都算），劍士立刻**往敵方方向瞬移 1/4 格**（`L.CELL_SIZE.x * blink_step`）。
- 一個擋路的敵人大約要打它 4 下，劍士就會閃到那個敵人身後。
- 閃過去以後**優先攻擊前方的敵人**（往敵方城門那一側）；前方攻擊距離內沒有敵人時，才回頭打身後最近的。
- 閃爍不能越過敵方城門：最多停在城門前，城門破了也要照規則拆殘垣。
- 被擊退時（火罐、耕牛）先算擊退再算閃爍。
- 同一瞬間受到多次傷害（例如箭雨＋箭樓）時，每次都閃一次。如果實測一下子閃太遠，加一個 0.2 秒的內部冷卻，並在本文件記下。
- 特效：原地留下紫色殘影，目的地閃一下（沿用傳送法陣的光效，縮小）。

**AI**：不加標籤，一般進攻時出。

## 2. 奧術魔像（`arcane_golem`）

**定位**：法師的前排，S 檔肉盾。和水晶、工匠連動：顧好經濟、帶上工匠，魔像就扛得更久。

| 欄位 | 值 |
|---|---|
| 人數 | 1 |
| 生命 | S |
| 傷害 | C |
| 攻擊間隔 | E |
| 射程 | G（近戰） |
| 移速 | F |
| 共鳴 | `"resonance": 0.1`、`"resonance_max": 0.3` |
| 崩解 | `explosion_damage` 範圍傷害 C、`radius` 範圍 C |
| AI | `"ai": ["hold"]` |

**機制**
- **共鳴**：我方場上每有一座水晶，魔像受到的傷害減少 10%，最多 30%（3 座）。每次受傷時即時計算，水晶被拆就立刻失效。
  - 和盾衛的 `armor` 不同：`armor` 是每下扣固定值，共鳴是按比例減傷，對大傷害也有效。
- **可修補**：工匠除了修友方建築，也會修附近受損的**奧術魔像**，修理量、間隔、距離跟修建築一樣。
  - 選目標的規則：在工匠的維修距離內，先選受損最多的魔像，沒有才選建築。
  - 工匠平常是停下來修東西；魔像會往前走，所以工匠要**跟著魔像前進**（以魔像的移速為上限），不能停在原地。
  - 接點：`arcane_mechanics.gd` 的 `repair()`。目前只找建築，要把魔像加進候選目標。
- **崩解**：死亡時對範圍內的敵方部隊造成範圍傷害（寫法同骨牆）。
- 身上的水晶紋路亮度跟著共鳴層數（0／1／2／3）變化，讓玩家看得出要保護水晶；被修補時顯示工匠修建築的同一種特效。

## 3. 奧術射手（`arcane_archer`）

**定位**：法師對付人海（骷髏兵、暴民、民兵）的手段。單發傷害低，但一箭打穿整排。

| 欄位 | 值 |
|---|---|
| 人數 | 3 |
| 生命 | F |
| 傷害 | E |
| 攻擊間隔 | D |
| 射程 | B |
| 移速 | E |
| 新欄位 | `"projectile": true`、`"pierce": true` |

**機制：貫穿**
- 光箭從射手射向目標，**同一路上從射手到攻擊距離兩倍的所有敵方部隊**沿途受到傷害（2026-11-03 製作人追加：索敵距離不變）（只算本路，不算相鄰路）。
- 目標是建築或城門時，路上的敵兵照樣被打穿，建築本身也受傷。
- 飛行單位也會被打到。潛行中的強盜不會被選為目標，但被打穿時照樣受傷並現身（同範圍傷害的規則）。
- 光矢飛行時間沿用 `ARROW_TIME`；畫面上是一支帶短紫色尾跡的飛行光箭，不是雷射；依飛行進度沿途命中，每個單位每箭最多受傷一次。

**AI**：不加標籤。

## 4. 時滯術士（`chronomancer`）

**定位**：控場。傷害很少，但每一下都讓周圍的敵人停頓一瞬間，打亂對方前排的攻擊節奏，讓我方部隊推得動。

| 欄位 | 值 |
|---|---|
| 人數 | 1 |
| 生命 | D |
| 攻擊 | 範圍傷害 G（寫成 `area_damage`，跟祕法塔一樣） |
| 攻擊範圍 | `radius` 範圍 E（落點周圍一小團） |
| 攻擊間隔 | D |
| 射程 | C |
| 移速 | E |
| 新欄位 | `"stun_on_hit": 0.5`（秒） |
| AI | `"ai": ["no_defend"]` |

**機制：命中暈眩**
- 每次攻擊在目標落點造成小範圍傷害，範圍內每名**敵方部隊**暈眩 0.5 秒（不能移動、不能攻擊）。
- 暈眩不疊加時間，只刷新成 0.5 秒（已經暈更久的不縮短，例如被傳送法陣暈的）。
- 不暈領主、建築、城門；範圍傷害仍會打到它們。
- 暈眩沿用傳送法陣已有的暈眩狀態，不要另做一套。
- 特效：落點出現一圈淡紫色鐘面閃一下；被暈的敵兵頭上有一個小沙漏。

## 5. 相位騎兵（`phase_rider`）

**定位**：法師缺少能直接威脅城門的單位。騎兵像幽靈一樣穿過敵方防線，直到碰到建築或城門才現形攻擊。

| 欄位 | 值 |
|---|---|
| 人數 | 2 |
| 生命 | C |
| 傷害 | B |
| 攻擊間隔 | D |
| 射程 | G（近戰） |
| 移速 | B |
| 新欄位 | `"phase": true` |
| AI | `"ai": ["raid"]` |

**機制：相位（不限時間）**
- 登場就進入相位，**一直持續到第一次攻擊**為止：
  - 不會被敵方部隊、領主、建築的普攻選為目標（沿用強盜的 `stealthed` 判斷）。
  - 不會停下來打敵方部隊，也不會被敵兵擋住，直接穿過去。
  - 範圍傷害（法術、爆炸、祕法塔、投石車、時滯術士）**照樣打得到**，跟強盜一樣。
  - 不觸發陷阱。
- 碰到敵方建築或城門就停下攻擊，相位結束，之後變回一般近戰部隊。
- 跟強盜的差別：強盜潛行時還是會被擋、會停下來打兵；騎兵直接穿過防線，只停在建築前。
- 唯一的反制是範圍傷害和建築擋路，所以要在測試裡確認它不會無傷直衝城門太多次（看平衡報告的「第一次破門時間」）。
- 特效：相位中半透明、帶藍紫色殘影；現形時閃一下。

## 實作清單（照《新增卡牌指南》的順序）

1. `balance.gd`：陣營、五張牌（數值從檔次表抄）、`validate()` 檢查新欄位：
   - `blink_step` 介於 0–1
   - `resonance`／`resonance_max` 介於 0–1
   - `pierce`、`phase` 是布林值
   - `stun_on_hit` 介於 0–5 秒

   `card_description()` 每張各加一行說明。
2. 機制程式放在 `arcane_mechanics.gd`，`battle.gd` 只加少量接點（跟水晶、法陣的做法一樣）。工匠修魔像改 `repair()`。
3. 圖：手抄本風格，提示詞存在 `assets/manuscript-v1/magic-units-prompts.json`，用內建 image_gen；紅藍換色沿用既有流程。參考 `art-direction/illuminated-chronicle-v1.png`。
4. 卡牌趣聞：`card_lore.gd` 五則，維持原本幽默諷刺的語氣與暗線。
5. 新增中文字後跑 `python tools/build_font.py` 並重新匯入。
6. 測試：寫 `tools/test_magic_units.gd`，接進 `quick_test.gd`，至少驗：
   - 劍士每次受傷往前閃 1/4 格；被同一個敵人打 4 下後位置在它身後；閃過後優先打前方；不越過城門。
   - 魔像 0／1／2／3／4 座水晶時減傷 0／10／20／30／30%；水晶被拆後立刻失效；工匠會修魔像並跟著它走；死亡爆炸。
   - 射手打穿同路所有敵兵，不打到相鄰路；會讓強盜現身。
   - 術士命中範圍內敵兵暈 0.5 秒；不暈領主和建築；不縮短更長的暈眩。
   - 騎兵相位中不被鎖定、不被擋、不觸發陷阱、範圍傷害打得到；第一次攻擊建築或城門後現形；相位沒有時間限制。
   - 法師能選這五張牌，其他領主不能選。
7. 截圖：`tools/capture_magic_units.gd`，圖鑑五頁＋五個機制的戰場畫面，放 `docs/magic-units-preview/`。
8. 只跑快速測試和專用測試；全量測試與黃金對局重錄等製作人說要整版發布時再跑（見 AGENTS.md）。

## 平衡驗收

- 實作完跑 `python tools/autobalance.py --total 1320 --rounds 3`，看五張牌的費用怎麼調，以及法師勝率。
- 目標：法師領主勝率 **45–55%**；五張新牌勝率各在 40–60%。
- 法師還是太弱時，先調這五張的費用，不要動數值檔次。真的要換檔，只往上或往下移一檔，並在本文件記下原因。
- 特別注意相位騎兵：相位不限時，最容易變成無解的破門手段。破門太快時先加費用或冷卻，再考慮把生命降一檔。
- 結果寫進新報告 `docs/法師新單位平衡報告.md`，並在 `docs/企劃書.md` 加版本紀錄。
