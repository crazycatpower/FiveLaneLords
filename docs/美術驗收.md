## 後續驗收標準與順序

1. 先修 A01／A02 的肢體與持盾結構，鐵壁領主一起複核。手可以被合理遮擋，但身體、手臂與道具的支撐關係必須成立。

3. 修 A04／A05／A09／A10：原比例、清晰度、裁切完整與 UI 可見範圍。
4. 最後統一農民／田地的紋理密度，以及小尺寸線條與隊色辨識。這些是風格改善，不冒充已確認的解剖錯誤。

每次修正須看原圖與實際尺寸兩種結果，重拍對應事件場景；功能測試另跑，不能取代目視驗收。
